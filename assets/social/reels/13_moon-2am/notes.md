# ur moon sign at 2am

**twelve moons, twelve 2am texts. 13.4s, loops.**
1080 x 1920, H.264 + AAC.

**Scheduled:** Saturday 19 September 2026, 20:00 IST

Twelve cards on hard cuts, one per moon sign, each one a text nobody should have
sent. Aries opens with "u up? no reason." Pisces closes with three apologies for a
message that was completely fine. Then the card stack cuts to a dark panel:
**comment ur moon sign**.

That last frame is the whole post. The twelve jokes exist to earn it. Every comment
is a person telling the algorithm this reel held them to the end, and telling us
which placement to write about next.

No voiceover. Sound design only, so a trending audio can go over the top inside
Instagram. Set the cover frame on the hook, not on frame 0, because the masthead
is still snapping in there.

Re-render: `python3 gencallout.py moon-2am`
from `.blogtools/social/`. Edit the data file, never the mp4.
